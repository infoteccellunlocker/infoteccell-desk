# Infoteccell Desk

Infoteccell Desk é um aplicativo portátil de acesso remoto para Windows 64 bits. Dois computadores se conectam pela internet usando um código temporário. Quem compartilha escolhe quando abrir a sessão e o que o outro computador pode controlar.

## Como usar

1. No computador que vai compartilhar, abra o Infoteccell Desk e clique em **Gerar código**.
2. Envie o código à pessoa que vai acessar. Ela cola o código no aplicativo e clica em **Conectar**.
3. Confira a solicitação e escolha o monitor. Marque **Mouse** e **Teclado** se quiser permitir esses controles. Com as duas opções desmarcadas, a pessoa pode apenas ver a tela.
4. Qualquer lado pode clicar em **Encerrar sessão**.

O código expira em cinco minutos e vale para uma tentativa de conexão. Para usar o aplicativo nos dois computadores, basta abrir o executável portátil. Os usuários do aplicativo não precisam de conta nem de VPN.
